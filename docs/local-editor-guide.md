# Adelaide Handyman MEL ONE 本地后台

双击桌面 **Adelaide Handyman MEL ONE 本地后台**。默认地址为 `http://127.0.0.1:4220/__editor/`；被占用时自动选择后续端口。再次双击复用当前服务。

1. 搜索并选择网页；左侧点选文字，或使用“文字位置”列表。
2. 在右侧修改中文，点击“保存中文草稿”。切换语言可查看原英文；宽度可选桌面或手机。
3. 改完在聊天告诉助手“读取本站后台草稿，同步中英文”，核对双语和 SEO 后，再单独授权上线。

正文、标题、FAQ、按钮、图片说明和 SEO 文字可编辑。导航、页脚、电话、邮箱、地址、价格等业务事实锁定；图片文件及内链网址由助手修改。与 Perth Handymate 后台操作一致，不支持直接新增页面、替换图片或自动翻译/发布。

保存写入本站 `.local-editor/drafts/`，不是浏览器缓存；不会更改正式源内容或线上网站。最近20次修订可恢复，恢复生成新修订。未保存切换会提醒；页面基线或草稿版本冲突会阻止覆盖并保留输入。

## 启动及交接

- `pnpm editor:dev` 启动；`node tools/editor/launch-local.cjs` 启动并打开浏览器。
- `pnpm editor:changes` 只读输出已保存的中文变更、英文原文、翻译 ID/位置，供助手逐项同步。输出可能含用户新写内容，不要公开上传。
- `pnpm editor:typecheck`、`pnpm editor:test` 检查后台。
- 双语同步按项目 AGENTS.md 更新原始内容和 `src/i18n`，记录已审核 ID，执行 build 和 check:bilingual。禁止绕过 source-lock，也不能只把中文草稿直接推上线。
- 共享文案可能用于多页；助手必须核对影响范围，保持标题与卡片 CTA 一致，不虚构业务承诺。应用后保留并核对旧修订，不删除用户草稿。

后台仅监听本机 127.0.0.1，Host/Origin/会话令牌保护写入，预览禁用询盘、邮件、外部脚本。它不是公网多用户后台，勿通过隧道或代理公开。程序、草稿、后台 UI 均不进入 public 发布目录。
